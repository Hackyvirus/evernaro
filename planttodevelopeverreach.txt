# EverReach — Complete Product UX, Dashboard & Implementation Specification

## Role

You are a senior SaaS product architect, UX designer, and full-stack engineer.

You are working on **EverReach**, an omnichannel customer messaging SaaS built by Eversity Tech LLP.

Your task is to transform the current application into a polished, production-ready SaaS product.

**IMPORTANT:**

Do NOT blindly rewrite the existing application.

First inspect the entire repository, understand the existing architecture and functionality, identify what already exists, and then implement the missing functionality incrementally.

Preserve working functionality unless there is a clear reason to improve it.

Do not create mock pages that only look good. Pages should be connected to the existing database, APIs, authentication, workers, channels, billing, and other infrastructure wherever those capabilities already exist.

---

# 1. Current Product

EverReach provides:

> One inbox for every customer conversation.

Supported channels:

* Telegram
* Email
* WhatsApp
* Instagram
* Voice reminders

Core capabilities:

* Unified omnichannel inbox
* Contacts
* AI-drafted replies
* Human approval before sending
* Business knowledge base
* Campaigns
* Scheduled reminders
* Recurring reminders
* Analytics
* WhatsApp template compliance
* WhatsApp prepaid wallet
* Billing
* Team management
* Channel configuration
* Organization settings
* Platform administration

AI replies are ALWAYS drafts.

EverReach must never autonomously send an AI-generated customer reply.

Human review and explicit send action are required.

# 2. Existing Technical Stack

Do not replace the existing stack unless absolutely necessary.

Current stack:

* Next.js 16
* App Router
* TypeScript
* Tailwind CSS v4
* Prisma 6
* PostgreSQL / Neon
* Auth.js / next-auth v5
* BullMQ
* Redis
* Sentry
* Razorpay
* Vitest

Architecture:

* Multi-tenant organization model
* Every organization-owned database record is scoped using orgId
* Organization authorization is revalidated against the database
* Channel credentials are encrypted at rest
* Background worker handles campaigns/reminders/voice
* WhatsApp 24-hour template enforcement exists
* Razorpay billing integration exists
* Sentry integration exists

Preserve and strengthen existing security architecture.

1. authenticated user

3. role permissions
4. organization ownership of requested resource

* cross-tenant data access

* never returned to frontend
